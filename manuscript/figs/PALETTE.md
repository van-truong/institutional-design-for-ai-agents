# Shared figure palette (LNCS manuscript)

A single muted, journal-ready palette used across all figures for visual harmony.
Inspired by the pennsieve-ai-coscientist figure system. Colors repeat across figures;
some symbolism is approximate (harmony is prioritized over one-color-per-concept).

## Semantic roles (Figs 1, 3, 4)
- **Amber / ochre** = institutional functions & mechanisms ("what an institution does")
- **Violet** = mechanism families / influence channels ("how behavior is shaped")
- **Green** = position / positive / accepted outcomes
- **Blue** = data, shared resources, information
- **Slate** = structure, ink, neutral scaffolding
